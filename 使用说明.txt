  DSH 机器人 安装说明 · 小白版（双击安装，不用敲命令）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

整个安装就干两件事：
  ① 装「本体」 —— Git、Node、DSH（以后升级本体也是跑这一条）
  ② 装「机器人」—— 建工作区、绑 Telegram、绑微信，并在工作区里放好
     start / stop / restart / install-autostart / uninstall-autostart 五个文件
下面的安装包把这两件事一次做完；会用终端的人也可以走在线命令（两种装出来一样）。

─────────────────────────────────
【在线装（会用终端的人才需要）】
  第一条（装/升级本体，机器上没有 dsh 时先跑这条）：
    curl -fsSL https://raw.githubusercontent.com/aitcmhk-web/DSH-bot/main/setupdsh.sh | sh
  第二条（建工作区 + 绑 TG / 微信）：
    curl -fsSL https://raw.githubusercontent.com/aitcmhk-web/DSH-bot/main/setupbot.sh | sh
  跑完这两条，终端里就多了 setupdsh 和 setupbot 两个词：
    setupdsh ＝ 升级（Git / Node / DSH 本体 + 已经装过机器人的工作区里的插件）
    setupbot ＝ 建工作区、首次装插件、重新绑 TG / 微信、重建那五个文件

─────────────────────────────────
【第 1 步 · 拿 token】
  打开 Telegram，搜索 @BotFather，发送 /newbot，
  按提示起两个名字，它会给你一串 "数字:字母" —— 复制它。

【第 2 步 · 双击安装】
  双击安装包里的 安装-mybot.command，然后照着屏幕回答就行：
  · 机器上没有 dsh 时，它会先自己装一遍本体（一两分钟），不用你管。
  · 如果它列出「已有这些工作区」：第一次装直接按回车（= 新建一个）。
  · 问新工作区名字：直接按回车就叫 mybot，也可以自己起一个。
  · 让你粘 token：粘贴 + 回车。
  · 问微信：先按 2 跳过，想用微信再回来绑（见下面【加微信】）。
  全程不用你编辑任何文件。窗口最后会停住 —— 看到 ✅ 再按回车关掉。

【第 3 步 · 启动】
  双击：~/DSH/mybot/start.command
  （工作区名字不是 mybot 的话，路径里的 mybot 换成你起的名字）
  机器没有桌面（云主机 / 只有终端）时：cd ~/DSH/mybot 然后敲 ./start.command
  看到「Telegram 已登录：@你的机器人名」就成功了。
  去 Telegram 找你的新机器人，随便发一句话——
  它会先回「🔐 你已成为主人」，然后正常回答你。

【工作区里那五个文件（都在 ~/DSH/你的名字/ 里）】
  名字都是英文（云主机没有桌面，只能进文件夹敲，中文得切输入法）；
  有桌面就双击，没桌面就在那个文件夹里敲 ./文件名。
  start.command               —— 开始干活（在后台跑，窗口关掉也照样活着）
  stop.command                —— 让它停下来（要退出就先停，别直接关窗口）
  restart.command             —— 升级 / 改完设置后用这个
  install-autostart.command   —— 开机自动启动（装好后再重启电脑，它自己就起来了）
  uninstall-autostart.command —— 取消开机自动启动（想手动开就再跑 start）

【加微信（可选）】
  ① 把 安装-mybot.command 再双击一次（或在终端敲 setupbot）
  ② 到微信那一步选「1. 重新扫码，绑一个」
  ③ 用手机微信「扫一扫」屏幕上的二维码（约 2 分钟过期，会自动刷新）
  ④ 跑一次 restart.command（双击，或终端里 ./restart.command），用扫码的那个微信发消息即可 —— 只有它能用。

【换 token / 重新绑 TG】
  还是老办法：再双击一次 安装-mybot.command（或敲 setupbot），
  TG 那一步直接粘新的 token；想沿用原来的，按回车再输编号就行。

【升级（Git / Node / DSH / 插件）】
  在终端敲 setupdsh；没装过这个命令，就把上面【在线装】第一条再跑一次。
  已经装过机器人的工作区，插件会一起升到最新，并告诉你「原版本 → 新版本」。
  升完跑一次 restart.command 才生效。

【停止 / 再次使用】
  停止：跑一次 stop.command。
  再次使用：跑一次 start.command。

─────────────────────────────────
常见问题
· 报 409 Conflict：这个 token 有别的程序在用（换一个新 bot 或停掉那个程序）。
· 发消息没反应：跑一次 stop.command 再跑一次 start.command，然后看 ~/DSH/你的名字/bot.log 最后几行。
· 想换模型：在 web 端「设置 → 模型」里增减 —— 下一条消息就生效；/model 可看列表。
· 聊天记录存哪：~/DSH/你的名字/memory/ 里（流水账按月一个文件；/new、切模型时自动留 handoff 接续档）。
· 微信扫码没反应：直接扫屏幕，别复制链接到电脑浏览器（会显示已过期）。

⚠️ 重要：这个新机器人和你已有的任何 bot 互不影响，但也不要共用同一个 token。
