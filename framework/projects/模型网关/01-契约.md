# 契约 · 模型网关

> 只有总控能改；模块要改先报总控，不许自己动手。

## 全局约定

- 运行环境：node（ESM，.mjs），HTTP 用 node 内置 http/fetch，无第三方依赖
- 代码位置：modules/<模块名>/，出了自己目录不许写
- **零业务数据**：模型表 = 配置文件 模型表.json（含 key，不进 git；模板 模型表.example.json）
- **key 只存这里**：任何模块调模型都报名字走本网关，永远不碰 key
- 每条模型记录：{ 名字, 地址, key, 参数 }——填 localhost=本地，填云端=线上，同一填法，代码不分家
- 项目之间：默认隔离；「消息窗口」是本网关的合法客户（转文字）
- 任务状态：待认领 → 进行中 → 待验收 → 完成 / 打回

## 模块清单

| 模块 | 对外接口 | 依赖 |
|---|---|---|
| registry | add / remove / update / list（名字→记录） | 无 |
| api | GET /models；POST /call {模型名, 输入} | registry |
| stt | 本地转写服务：POST /v1/audio/transcriptions {文件} → {文本}（FunASR SenseVoice，端口 9911，只听本机） | 系统依赖 ffmpeg、python funasr |

## 接口明细

### registry

- 表文件：模型表.json（数组，一条一个模型）；改动只动表文件，代码不动
- list() → 名字数组；get(名字) → 记录（key 只在网关内部用，绝不外吐）

### api

- GET /models → 名字列表（不含 key）
- POST /call {模型名, 输入} → 按表转发到该模型的地址（附 key）→ 原样返回输出
- 模型名不在表里 → 400，报「模型未登记」；表里有但地址不通 → 502，报「模型不可达」

### AITCM 信封（2026-10-06 扩，主 bot 补录；key 只存本网关）

- POST /call 同时认 AITCM 报名字信封：`{ 项目:'AITCM', 模块:'咨询|舌象|医师|客服', 载荷 }` → 查模型表「AITCM·<模块>」条目（`参数.model` = 上游模型名，其余参数并入上游请求体）；未登记 → 400 报「模型未登记（AITCM·<模块>）」
- 翻译规则（载荷 100% 透传、不发明内容）：system = 提示词/审查要求/形状说明/修正指令（有哪个拼哪个，`\n\n` 连接）；`载荷.图片{base64,mime}` → data URL image_url 放 user 最前；其余字段按出现顺序进 user 文本（字符串原样、对象/数组 JSON 序列化、行首「字段名：」；chatId 内部字段不上送）
- 响应 = `{ 原文: choices[0].message.content }`；上游解析不出 choices → 502 带上游返回摘录
- 原 `{模型名, 输入}` 直通口不动（消息窗口转文字仍走它）
- 模型表已补录四条：AITCM·咨询 = qwen3.7-flash、AITCM·舌象 = qwen3-vl-plus、AITCM·医师 = qwen3.7-plus（实测带图可用）、AITCM·客服 = qwen3.7-flash（阿里 DashScope 兼容口，key 本机保密不外传）
