# 规划 · 模型网关

> 总控专属。目标、拆模块、里程碑。

## 目标（一句话）

公共地基②——全框架统一的模型调用口：模型表集中管理，key 只存这里，任何模块**报名字**就能调模型；本地/线上同一填法。

## 模块拆分

| 模块 | 干什么 | 为什么单独拆 |
|---|---|---|
| registry | 模型表（配置文件）的增删改查 | 表只此一份，改表不改代码 |
| api | HTTP 口：列模型、按名字调用 | 调用方只认接口 |
