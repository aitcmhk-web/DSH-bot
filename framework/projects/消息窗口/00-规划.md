# 规划 · 消息窗口

> 总控专属。目标、拆模块、里程碑。

## 目标（一句话）

公共地基①——全框架统一的对外消息通道：收发 TG/微信消息、格式归一、可选转文字；**零业务数据**，顾客对话数据全归各项目自己的库。

## 模块拆分

| 模块 | 干什么 | 为什么单独拆 |
|---|---|---|
| access | 对接通道收发消息（TG 先做，微信第二批） | 通道细节集中一处 |
| convert | 格式归一（下载/转码/统一形状）；语音转文字=可选开关 | 转换做一次全项目受益 |
| route | token→归属项目 路由，把消息递给项目 | 路由靠配置，零数据库 |
| api | 对项目暴露 HTTP 口（发送/健康检查） | 项目只认接口 |
