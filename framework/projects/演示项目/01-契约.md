# 契约 · 演示项目

> 模块之间怎么对接。只有总控能改；模块要改先报总控，不许自己动手。

## 全局约定

- 运行环境：node（ESM，.mjs），无第三方依赖
- 代码位置：modules/<模块名>/，出了自己目录不许写
- 数据：一律 import data 模块接口，谁也不许直连 本地数据/；真数据在 本地数据/（不进 git）
- 项目之间：默认隔离；要用别的项目只能走对方契约写明的接口，⛔ 不许直接读对方目录的代码或数据
- 任务状态：待认领 → 进行中 → 待验收 → 完成 / 打回

## 模块清单

| 模块 | 对外接口 | 依赖 |
|---|---|---|
| data | import { read, write } from '../data/data.mjs' | 无 |
| hello | 无对外接口（终端演示入口） | data |

## 接口明细

### data

- 表结构：modules/data/表结构.md（改表 = 改契约，过总控）
- read(表, 条件?) → 数组；条件省略返回全部
- write(表, 记录) → 落盘后的完整记录（自动带自增 id）
- 存储：本地数据/db.json（首次写入自动建）

### hello

- 运行：node modules/hello/hello.mjs → 调 data.write 存一条演示留言，再 data.read 打印条数
